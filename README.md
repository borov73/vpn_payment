## ✨ Возможности

- **💰 Баланс** — остаток в EUR, дата необходимого пополнения и недостающая сумма.
- **📜 Пополнения** — простая история: дата и сумма, с переключением страниц.
- **🔔 Напоминания** — за 7, 3 и 1 день, с учётом оплаты вперёд.
- **✅ Уведомление о платеже** — поступившая сумма, новый баланс и остаток после ближайшего списания.
- **🔎 Автоматическая проверка** — поиск подтверждённых ETH-переводов через Base RPC каждые 15 минут.
- **📈 Исторический курс** — ETH/EUR на момент платежа через CCXT, с резервным источником.
- **💾 Сохранение истории** — SQLite, резервные копии и продолжение работы после перезапуска.

Бот читает блокчейн и доступен только владельцу. Приватные ключи и seed-фразы не нужны.

## 📱 Как это выглядит

Пример карточки с условными данными:

```text
💰 Баланс VPN

6,00 €

📅 Пополнить до 15.01.2027
Нужно 2,00 € на следующие 30 дней.

4,00 € / 30 дней

[ 💰 Баланс ]  [ 📜 Пополнения ]
```

Текущая модель — **4 € за 30 суток непрерывного использования**. Неполный остаток
сохраняется, оплата вперёд сдвигает срок пополнения. Это собственный расчёт:
курс EUR является рыночной оценкой, а условия и фактический биллинг провайдера боту неизвестны.

## 📦 Установка

Нужны **Python 3.12+**, Git и Telegram-бот, созданный через [@BotFather](https://t.me/BotFather).
Инструкция ниже подходит для macOS и Linux.

**1. Скачай проект:**

```bash
git clone https://github.com/borov73/vpn_payment.git
cd vpn_payment
```

**2. Создай окружение и установи зависимости:**

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

**3. Создай личную конфигурацию:**

```bash
cp -n .env.example .env
chmod 600 .env
```

## ⚙️ Настройка

Открой `.env` в текстовом редакторе и заполни:

| Переменная | Что указать |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `TELEGRAM_USER_ID` | Свой числовой Telegram User ID |
| `BASE_RPC_URL` | Адрес RPC сети Base с поддержкой исторического состояния |
| `SENDER_ADDRESS` | Кошелёк, с которого оплачивается VPN |
| `RECIPIENT_ADDRESSES` | Все адреса провайдера для учёта прошлых платежей, через запятую |
| `ACTIVE_RECIPIENT_ADDRESSES` | Только действующие адреса для новых платежей |
| `HISTORY_START` | Начало поиска в UTC, не позднее первого учитываемого платежа; например `2026-01-01T00:00:00Z` |
| `SUBSCRIPTION_START` | Подтверждённое начало расчёта в UTC; пустое значение означает предварительный расчёт |

**Заполни адреса и даты своими данными:** персональных реквизитов в образце нет.
Адреса и `HISTORY_START` обязательны. Дату поиска для уже созданной базы не меняют:
для другого кошелька или диапазона используй отдельный `DATABASE_PATH`.
Цена и период задаются через `MONTHLY_PRICE_EUR` и `PERIOD_DAYS`. Начальные параметры
применяются при создании базы; изменение сохранённых правил описано в [справке](docs/REFERENCE.md).

`.env`, база, логи и резервные копии исключены из Git.
Публичный исходный код не предоставляет доступ к твоему VPS или Telegram-боту:
SSH требует твоего ключа/пароля, бот проверяет `TELEGRAM_USER_ID`.

## 🚀 Запуск

Проверь подключение и загрузи историю:

```bash
source .venv/bin/activate
python -m vpn_payment doctor --online
python -m vpn_payment sync
```

Запусти бота:

```bash
python -m vpn_payment run
```

Открой своего бота в Telegram и нажми **Start**. Дальше доступны две кнопки:
**💰 Баланс** и **📜 Пополнения**. Проверки и уведомления работают автоматически.

Остановка — `Ctrl+C`. Запускай только один экземпляр бота с одним токеном.
Если RPC не позволяет восстановить историю, доступен [импорт известных транзакций](docs/REFERENCE.md#история-native-eth-через-rpc).

## ☁️ Работа на сервере

Чтобы бот работал круглосуточно при выключенном компьютере, установи его на Ubuntu VPS.
В проекте подготовлены systemd-сервис с автозапуском и ежедневные копии базы
с автоматическим удалением копий старше 5 суток.

**[Пошаговая инструкция: FirstByte → Termius → установка → запуск → обновления](deploy/README.md)**
